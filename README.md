# WaterWorld (web)

First-person ocean seed — Gerstner waves, swim controls, underwater murk. Built with Vite + Three.js.

## Local

```powershell
npm install
npm run dev
```

## Controls

- **Touch / on-screen:** left stick move · right stick look · ▲▼ depth
- **Desktop:** WASD · click for mouse-look · Space/E up · Shift/Q dive
